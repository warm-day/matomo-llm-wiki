# Dashboards

**Summary**: Customizable reporting areas that allow users to group specific widgets and charts for regular monitoring.

**Sources**: [[../../raw/Matomo Analytics DB 74e2f6cb8f0549379ec3cbe6c6a1a066.md]]

**Last updated**: 2025-05-23

## Creating a Dashboard
1. Navigate to the **Dashboard** section.
2. Click the **Dashboard button** and select **"Create new dashboard"**.
3. Choose between an **Empty dashboard** (recommended) or the default layout.
4. Click **"Add A Widget"** to browse and select reports to display (source: Matomo Analytics DB 74e2f6cb8f0549379ec3cbe6c6a1a066.md).

## Managing Widgets
- **Widget Menu**: Hover over the top right of a widget card to access **Refresh, Minimize, Maximize,** and **Close** options.
- **Layout**: Use the **"change dashboard layout"** button in the dashboard menu to adjust the number and width of columns (source: Matomo Analytics DB 74e2f6cb8f0549379ec3cbe6c6a1a066.md).
