# Transitions Report

**Summary**: A detailed report showing user actions immediately before and after viewing a specific page.

**Sources**: [[../../raw/Matomo Analytics DB 74e2f6cb8f0549379ec3cbe6c6a1a066.md]]

**Last updated**: 2025-05-23

---

## Launching Transitions
- **Navigation**: Access from **Behaviour > Pages** or **Behaviour > Page Titles**.
- **Activation**: Hover over a row and click the **Transitions icon (X)** (source: Matomo Analytics DB 74e2f6cb8f0549379ec3cbe6c6a1a066.md).

## Report Structure
The report centers on a specific page, with incoming traffic on the left and outgoing actions on the right. Connection height is proportional to traffic volume.

### Previous Actions (Left Side)
- **From Internal Pages**: Visitors navigating from other pages on the same website.
- **From Search Engines**: Direct traffic from external search engines (e.g., Google).
- **From Websites**: Traffic from external referral links.
- **From Internal Searches**: Keywords used in the site's internal search engine prior to viewing the page.
- **Direct Entries**: Visits that used the current page as their landing page.

### Current Page (Center)
- Displays the total number of pageviews and their share of overall site traffic.

### Following Actions (Right Side)
- **To Internal Pages**: Navigation to other site pages.
- **Internal Searches**: Keywords searched while on the current page.
- **Downloads and Outlinks**: Clicks on file downloads or external links.
- **Exits**: Visits that terminated on this page (no further actions tracked) (source: Matomo Analytics DB 74e2f6cb8f0549379ec3cbe6c6a1a066.md).
