# Page Overlay

**Summary**: A feature that overlays analytics data directly onto the tracked website, visualizing click patterns through interactive bubbles.

**Sources**: [[../../raw/Matomo Analytics DB 74e2f6cb8f0549379ec3cbe6c6a1a066.md]]

**Last updated**: 2025-05-23

---

## Launching Page Overlay
- **Navigation**: Access from the **Behaviour > Pages** report.
- **Activation**: Hover over a specific page row and click the **bubble icon** (source: Matomo Analytics DB 74e2f6cb8f0549379ec3cbe6c6a1a066.md).
- **Display**: The website opens in a new tab with bubbles next to links indicating click counts.

## Key Characteristics
- **Visual Feedback**: Bubbles show how many visitors clicked each link.
- **Non-Real-Time**: Data displayed is historical and not updated in real time (source: Matomo Analytics DB 74e2f6cb8f0549379ec3cbe6c6a1a066.md).
