# Crash Analytics

**Summary**: An extension for Matomo that logs unexpected errors and failures in websites or applications to improve user experience.

**Sources**: [[../../raw/Matomo Analytics DB 74e2f6cb8f0549379ec3cbe6c6a1a066.md]]

**Last updated**: 2025-05-23

---

## Overview
- **Function**: Automatically logs unexpected errors occurring within the application or website.
- **Goal**: Provides insights into failures that impact user experience.
- **Availability**: Available as an extension on **matomo.org** (source: Matomo Analytics DB 74e2f6cb8f0549379ec3cbe6c6a1a066.md).
